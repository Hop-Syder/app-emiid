## 🔴 Le Problème — Un continent riche en talents, pauvre en confiance

L'Afrique est le continent le plus jeune du monde.
**60 % de la population a moins de 25 ans.** Les talents sont là.
Les opportunités ? Aussi. Mais il manque **une infrastructure de confiance**.

- 🤝 Un recruteur cherche un développeur qualifié. Il passe par WhatsApp. Il contacte 30 personnes. Il en retient 2. **Il a perdu 2 semaines.**

## 🏗️ Traction — Ce qui est déjà construit (v1.2.0)

**Nexus Connect n'est pas une idée. C'est un produit.**

### Ce qui fonctionne aujourd'hui

- ✅ **Authentification** : Multi-méthodes (Email / OAuth), sécurisée par JWT et cookies SSR.
- ✅ **Profils** : Création, édition, publication/dépublication avec gestion des tags et secteurs.
- ✅ **Annuaire intelligent** : Recherche multi-critères (secteur, pays, ville, compétences).
- ✅ **Messagerie temps réel** : Chat instantané, marquage de lecture, partage de fichiers.
- ✅ **Réseau** : Système follow/unfollow avec compteurs synchronisés en temps réel.
- ✅ **Médiation** : Support intégré et système de litige entre utilisateurs.
- ✅ **Sécurité** : Row Level Security (RLS) Supabase, protection par code PIN.
- ✅ **Admin Cockpit** : Dashboard de modération et gestion des utilisateurs opérationnel.

### Stack Technique

```
Frontend User   : Next.js 15  · TypeScript · Tailwind CSS · Supabase SSR
Frontend Admin  : Next.js 16  · TypeScript · Tailwind CSS 4 · Framer Motion
Base de données : PostgreSQL  · Supabase  · Row Level Security · Realtime
Architecture    : Monorepo    · App Router · i18n FR/EN
```
